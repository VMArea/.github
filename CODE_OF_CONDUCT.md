# Code of Conduct

VMArea's open-source projects follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

It applies in all project spaces, including issues, pull requests and discussions, and when representing a project in public.

To report unacceptable behaviour, email [hello@vmarea.com](mailto:hello@vmarea.com). Reports are reviewed promptly and handled in confidence.
