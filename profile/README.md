# VMArea

Cloud servers that just run.

VMArea is a cloud hosting provider. Fixed monthly prices in your currency, no long-term contract, and a server that stays in the location you pick.

- **Cloud VPS**: Linux and Windows servers by the month, on NVMe storage.
- **Dedicated servers**: whole machines for heavy, steady work.
- **One-click apps**: popular apps, ready on first boot.
- **Firewalls**: stateful, default-deny inbound, with rules you control.
- **Snapshots and backups**: restore points and daily copies.
- **API and webhooks**: a REST API with scoped keys and signed webhook events, in early access.

## Open source

- `app-recipes`: hardened one-shot installers for 14 open-source apps on Ubuntu 24.04. Coming soon.
- `vmarea-js`: a TypeScript SDK and the `vmarea` CLI for the public API. Coming soon.
